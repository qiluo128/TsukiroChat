## 文档约定

- 需求编号：`FR-<模块>-<序号>` 功能需求，`NFR-<类别>-<序号>` 非功能需求。
- 权限名：`<域>.<动作>`，如 `media.read`、`sys.clipboard.write`。
- 原语名：`<域>.<动作>`，如 `sys.time`、`model.chat`。
- 代码标识符、路径、JSON 字段一律用 `code` 样式。
- 「**预留**」标记 = 本阶段只定义接口，不实现，但字段和数据格式一次留全，未来不重构。
- 所有图使用 ASCII / Mermaid，保证纯文本可读。

## 变更流程

1. 改对应文档，在文末「变更记录」追加一行。
2. 若属重大设计变更，在 [14-decisions.md](14-decisions.md) 新增一条 ADR。
3. 文档变更与代码变更放在同一个提交里。
